# Report fonts

Noto Sans Regular and Bold are bundled locally for PDF reports, including Latin diacritics and Greek metric symbols. No remote font requests are made during analysis or report generation.

Source: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans
